# Privacy Policy — Browser Supply List

Effective date: 2026-09-19

Browser Supply List helps a user collect product details from shopping pages and save them to a Google Sheets worksheet selected by that user.

## Data the extension handles

- The Google Sheets worksheet URL, selected worksheet ID, field mappings, field-visibility preferences, and acceptance of the privacy notice are stored locally in Chrome.
- After the user grants access to an individual shopping site, the extension reads product-page details such as title, price, image URL, product ID, description, and page URL.
- After the user authorizes Google access and chooses Add, Update, or Remove, the extension reads from and writes to the selected Google Sheets worksheet.

## How data is used and shared

The extension uses this data only to provide the supply-list feature. Product details are sent only to the Google Sheets API for the worksheet selected by the user. The extension has no developer-operated server, analytics service, advertising service, or data broker. It does not sell, rent, share, or use data for advertising.

The extension does not collect Google passwords. Chrome manages the Google authorization token through its built-in identity system.

## User control

Users choose each shopping site to allow, choose the destination worksheet, may disconnect that worksheet, and can remove site access through Chrome’s extension settings. Removing the extension removes its locally stored settings.

## Google API Limited Use disclosure

Browser Supply List’s use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
